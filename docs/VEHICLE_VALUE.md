# 차량 특화성과 운전자 가치

## 차량 특화성

- **AAOS 네이티브 앱**: `android.hardware.type.automotive`를 선언하고 주행 중 화면 제한(UX Restrictions)을 지킨다. 글자 입력 없이 음성만으로 쓰도록 설계했다.
- **차량 신호 활용**: 기어 P와 시동 상태로 주차 순간을 알아내 위치를 자동 저장한다. Pleos 에뮬레이터에서 서드파티 앱이 시동 신호를 읽을 수 없다는 점을 확인하고, 'P 유지 시간' 규칙을 추가했다.
- **차 안 환경 고려**: 호출어 기준값을 사용자 녹음으로 계산한다. 휴대폰용 시험판에는 스피커 소리 오인식을 줄이는 장치(AEC, 재생 중 기준 강화)를 넣었다.

## 창의성

- **내 목소리 호출어**: 정해진 단어가 아니라 운전자 목소리로 등록한다. 3번을 일부러 다르게(목소리·속도·높낮이) 녹음해도 그중 하나만 맞으면 호출한다.
- **기기 내 처리**: 호출어·명령 해석이 네트워크 없이 동작한다. 터널이나 지하주차장에서도 쓸 수 있다.
- **운전 맥락 비서**: 앱 실행에 그치지 않고 주차 위치와 할 일을 함께 다룬다.

## 운전자 편의성

- 화면을 보지 않고 "카톡 열어줘", "최근 메시지 읽어줘", "곧 도착한다고 답장해 줘"로 처리한다.
- 내린 뒤에는 휴대폰에서 "차 어디 세웠지?"로 주차 위치와 길찾기를 받는다 (동기화 설정 시).
- 개인정보: 음성·녹음은 외부로 보내지 않는다.
