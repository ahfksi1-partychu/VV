# 향후 개발 계획

아래 항목은 모두 **아직 구현되지 않았다.**

## 1. Pleos 전용 SDK 연동

- 현재는 AAOS 표준 API(`CarPropertyManager` 등)만 쓴다.
- Pleos SDK(Vehicle, NaviHelper 등)를 정식으로 받으면 다음을 붙일 계획이다.
  - 시동·주행 상태를 정확히 받아 주차 감지 신뢰도를 높인다. 표준 API로는 서드파티 앱이 시동 신호를 읽지 못했다.
  - 차량 내비게이션에 목적지를 음성으로 바로 전달한다.
- 코드에는 연동 자리만 주석으로 남아 있다.

## 2. 차종 자동 인식

- 차량 정보(제조사·모델·연식 속성)를 읽어 차종을 자동으로 알아낸다.
- 차종에 맞는 안내(소모품 주기, 기능 설명)의 기반으로 쓴다.

## 3. 동일 차종 사용자 커뮤니티

- 같은 차종 운전자끼리 정비 경험, 유용한 설정, 문제 해결 팁을 나눈다.
- 운전 중에는 음성 요약만 제공하고, 정차 후에 자세히 본다.

## 4. AI 차량 관리 추천

- 주행 기록, 주차 기록, 차종 정보로 점검 시기와 소모품 교체를 추천한다.
- 운전 패턴에 맞는 할 일 제안(예: 주유, 세차, 정기 점검)

## 5. 실차 검증

- Pleos 실차 또는 개발 차량에서 호출어 인식률, 주차 감지, 주행 중 제한을 검증한다.
