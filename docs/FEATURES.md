# 기능과 구현 상태

상태 표기
- **구현**: 코드가 있고 빌드된다.
- **확인**: 에뮬레이터나 실기기에서 동작을 봤다.
- **예정**: 아직 구현하지 않았다.

## 차량용 (car, 공모전 제출 대상)

| 기능 | 상태 |
|---|---|
| 개인 호출어 등록 (녹음 3회, 품질 검사, 녹음별 독립 템플릿) | 구현. 5회 버전은 Pleos 에뮬레이터에서 확인했고, 3회 버전은 차량 환경에서 미확인 |
| 호출어 감지 (셋 중 하나 일치 시 호출) | 구현 |
| 음성 앱 실행 (이름·별칭·줄임말·종류) | 구현 · 에뮬레이터 확인 |
| 내 앱(즐겨찾기) 등록·별칭·실행 | 구현 · 에뮬레이터 확인 |
| 메시지 읽기·답장 (알림 접근) | 구현 |
| 주차 자동 기록 (AAOS `CarPropertyManager`: 기어, 시동, 주차 브레이크) | 구현 · 에뮬레이터에서 기어 신호 확인. 서드파티 앱은 시동 신호를 읽지 못해 'P 유지 시간' 규칙을 추가했다 |
| Drive To-Do (음성 할 일, "차 어디 세웠지?") | 구현 |
| 차량 ↔ 휴대폰 동기화 (Supabase, 종단 암호화) | 구현 · 오프라인 자체 시험 통과. 실서버 미검증 |
| 주행 중 화면 제한 준수 | 구현 |

## 휴대폰용 (phone, 참고용 — 차량용 APK에는 없음)

| 기능 | 상태 |
|---|---|
| 플로팅 버튼, 다른 앱 사용 중 호출 (큰 창 없이 버튼으로 상태 표시) | 구현 · 실기기 사용 |
| 스피커 소리 오인식 줄이기 (TTS 중 감지 중지, AEC, 재생 중 기준 강화) | 구현 · 효과 미측정 |
| 유튜브 검색 / "틀어줘" → 첫 일반 영상 선택 (접근성), 재생 확인 | 구현 · 영상 화면 진입은 사용자가 확인. 재생 유지는 미확인 |
| 유튜브 공식 '광고 건너뛰기' 버튼 누르기 | 구현 · 미확인 |
| 미디어 제어 (다음 곡·이전 곡·일시정지·재생) | 구현 · 미확인 |
| 지도 연동 (네이버지도 `nmap://navigation`, 구글 지도 길 안내) | 구현 · 미확인 |
| 무음 2초 뒤 명령 처리, 실행형 명령은 대답 없이 실행 | 구현 |
