# 화면 자료

모두 실제 앱 화면이다. 개발 중 Pleos 에뮬레이터에서 캡처했다.

| 파일 | 내용 |
|---|---|
| `01~12` | 내 앱 등록·별칭·실행 (차량용) |
| `20~22`, `first-run.png` | 첫 실행, 마이크 권한 |
| `23~27` | 호출어 등록 (당시 5회 녹음 버전. `26-inconsistent-take3`는 이후 삭제된 '재녹음 요구' 화면) |
| `28~31` | 음성비서 호출, 시스템 음성비서(Gleo)와의 공존 |
| `40~44` | 주차 위치 기록 질문, 사진 기록, 주차 카드, 알림, GPS 없는 경우 |
