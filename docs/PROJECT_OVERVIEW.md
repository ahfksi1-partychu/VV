# 프로젝트 개요 — VV쁘이

## 해결하려는 문제

1. **운전 중 화면 조작 위험**: 앱 하나를 열거나 메시지를 확인하려 해도 여러 번 눌러야 한다.
2. **획일적인 호출어**: 기존 음성 비서는 정해진 호출어만 쓸 수 있다. 차 안의 음악·대화에 잘못 반응하기도 한다.
3. **운전과 함께 생기는 정보가 흩어짐**: 주차 위치, 내리면서 해야 할 일 같은 정보를 따로 메모해야 한다.

## 해결 방식

| 문제 | VV쁘이의 접근 |
|---|---|
| 화면 조작 | 말로 앱 실행, 메시지 읽기·답장. 주행 중 화면 제한(UX Restrictions)을 지킨다 |
| 호출어 | 운전자 목소리로 3번 녹음한 개인 호출어. 셋 중 하나만 맞아도 호출하고, 인식은 기기 안에서 한다 |
| 운전 정보 | 기어 P·시동 신호로 주차를 감지해 위치를 저장한다. Drive To-Do로 할 일을 정리한다 |
| 개인정보 | 음성·녹음은 기기에만 둔다. 차량과 휴대폰 사이 동기화는 종단 암호화한다 |

## 대상 사용자

- 운전 중 메신저·내비게이션·음악을 자주 쓰는 운전자
- 주차 위치를 자주 잊거나, 운전 중 떠오른 일을 기록하고 싶은 운전자
